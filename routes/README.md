# routes

Маршруты приложения. Каждый файл — свой `APIRouter`, все они подключаются в [main.py](../main.py).

| Файл | Маршруты | Что делает |
|------|----------|-----------|
| `index.py` | `GET /` | Главная: опубликованные записи карточками, фильтры `category`, `tag`, `q`, пагинация `page` |
| `record.py` | `GET /record/{id}` | Страница записи; черновик и несуществующая запись дают 404 |
| `admin.py` | `GET /admin` | Список всех записей с поиском, фильтром по категории и статусу |
| | `GET /admin/new`, `POST /admin/new` | Форма новой записи и её сохранение |
| | `GET /admin/edit/{id}`, `POST /admin/edit/{id}` | Форма правки и сохранение |
| | `POST /admin/delete/{id}` | Удаление записи вместе с картинками, редирект на список |
| | `GET /admin/preview/{id}` | Предпросмотр записи, в том числе черновика |
| `taxonomy.py` | `GET /admin/taxonomy` | Страница тегов и категорий |
| | `POST /admin/taxonomy/tags/add`, `.../tags/{id}/rename`, `/delete`, `/merge` | Действия с тегами |
| | `POST /admin/taxonomy/categories/add`, `.../categories/{id}/rename`, `/delete`, `/move` | Действия с категориями |
| `admin_api.py` | `POST /admin/api/records/{id}/images` | Загрузка картинки (201) |
| | `PATCH /admin/api/images/{id}` | Изменить подпись `alt` |
| | `PUT /admin/api/records/{id}/images/order` | Новый порядок: `{"ids": [...]}` |
| | `DELETE /admin/api/images/{id}` | Удалить картинку (204) |

Кроме роутеров, в [main.py](../main.py) есть `GET /health` и HTML-страницы ошибок (404, 405, 500).

## Как устроен обычный роут

1. FastAPI через `Depends(db.get_db)` выдаёт сессию БД.
2. Данные формы собираются в `RecordForm`, основной текст очищает `sanitize_html`.
3. Функция из `data/` читает или пишет в БД.
4. Ответ — либо `templates.TemplateResponse(...)`, либо `RedirectResponse(..., 303)`
   (паттерн «POST → redirect → GET», чтобы форма не отправлялась повторно при обновлении страницы).

## Особенности

- Ошибки формы записи не бросают исключение: страница отрисовывается заново с кодом `422`,
  введённые значения сохраняются, сообщения показываются у полей.
- Ошибки справочников (`TaxonomyError`) показываются на странице тегов, также с кодом `422`.
- Ссылки с главной на запись несут текущие фильтры (`category`, `tag`, `q`, `page`), чтобы «назад» вёл на тот же
  список. Параметры берутся из белого списка (`utils/urls.py`), а не из заголовка `Referer`.
- JSON-эндпоинты картинок отдают ошибки в виде `{"detail": "..."}`, этот текст показывает `static/admin/images.js`.
  Код `400` — плохой файл или лимит, `409` — список порядка устарел, `404` — нет записи или картинки.
- Маршруты `/admin/...` **не защищены паролем**.
