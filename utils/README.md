# utils

Вспомогательный код, не привязанный к конкретной странице. Модули `text.py`, `images.py` и `backup.py`
берут настройки из [core.py](../core.py).

## Файлы

| Файл | Назначение |
|------|-----------|
| `logger.py` | Единая настройка логирования |
| `text.py` | Очистка HTML из редактора, нормализация названий, краткий фрагмент текста, поисковая строка |
| `images.py` | Проверка и обработка загруженных картинок, удаление их файлов |
| `backup.py` | Безопасная копия файла базы SQLite |
| `urls.py` | Ссылки на список с фильтрами из белого списка параметров |

## logger.py

| Функция | Что делает |
|---------|-----------|
| `setup_logging(level=None)` | Настраивает корневой логгер один раз за процесс (повторные вызовы ничего не делают) |
| `get_logger(name)` | Возвращает логгер с этим именем и заодно гарантирует, что логирование настроено |

```python
from utils.logger import get_logger

logger = get_logger(__name__)
logger.info("Something happened")
```

Формат строки: `время | уровень | имя модуля | сообщение`. Уровень берётся из `LOG_LEVEL` в `.env`
(по умолчанию `INFO`). Служебные логи `uvicorn.access` и `sqlalchemy.engine` приглушены до `WARNING`.

## text.py

| Функция | Что делает |
|---------|-----------|
| `sanitize_html(value)` | Оставляет только разрешённые теги (`p`, `br`, `h2`, `h3`, `strong`, `em`, `u`, `s`, `ul`, `ol`, `li`, `blockquote`, `a`), заменяет `&nbsp;` на обычные пробелы, пустой Quill-текст (`<p><br></p>`) превращает в `""` |
| `normalize_key(value)` | Ключ для сравнения без учёта регистра, `ё` = `е` (в SQLite для кириллицы своих средств нет) |
| `clean_name(value)` | Название тега или категории без лишних пробелов |
| `html_to_plain(value)` | Текст без разметки |
| `excerpt(value, limit=150)` | Начало текста для карточки, обрезается по слову с многоточием |
| `build_search_text(title, description)` | Строка, по которой идёт поиск (`Record.search_text`) |

Используется библиотека `nh3`. Список разрешённых тегов и атрибутов лежит в начале файла.
Ссылки получают `rel="noopener noreferrer"`, разрешены только схемы `http`, `https`, `mailto`.
Картинки в тексте запрещены: они хранятся отдельно (`Image`).

## images.py

| Функция | Что делает |
|---------|-----------|
| `process_upload(data)` | Проверяет файл, превращает в WebP до 1600 px, рядом кладёт миниатюру 480 px, возвращает имя `<uuid>.webp` |
| `delete_image_files(filenames)` | Удаляет файл и его миниатюру, отсутствие файла не ошибка |

Правила: тип определяется по содержимому, а не по расширению; принимаются JPEG, PNG, WebP; GIF и анимация отклоняются;
EXIF-поворот применяется, метаданные (включая GPS) не сохраняются; защита от «бомб» (больше 50 млн пикселей).
Ошибки приходят как `ImageError` с текстом для пользователя.

## backup.py

`backup_database(prefix="app", keep=10)` копирует базу в `backups/<prefix>-<время>.db` через `sqlite3.backup`
(безопасно, пока база используется) и хранит последние `keep` копий с этим префиксом. Если файла базы ещё нет,
возвращает `None`. Вызывается командами `backup` и `import` из [cli.py](../cli.py).

## urls.py

`list_query(params)` и `with_query(path, params)` собирают строку запроса только из параметров `category`,
`tag`, `q`, `page`. Остальные отбрасываются, так «назад» нельзя превратить в открытый редирект.
