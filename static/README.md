# static

Файлы, которые браузер получает как есть. Отдаются по адресу `/static/...` (подключено в [main.py](../main.py)).

Папка раздаётся целиком, поэтому этот README тоже доступен по `/static/README.md`. Секретов здесь быть не должно.

## Файлы

| Путь | Что внутри |
|------|-----------|
| `style.css` | Общие стили сайта и цветовая палитра (CSS-переменные), подключается везде |
| `record.css` | Страница записи, подключается после `style.css` |
| `admin.css` | Админка, подключается после `style.css` |
| `admin/common.js` | Подтверждение по `data-confirm`, предупреждение об уходе с несохранёнными изменениями |
| `admin/editor.js` | Подключает Quill к полю «Основной текст», при отправке кладёт HTML в скрытое поле |
| `admin/images.js` | Менеджер картинок записи на Vue 3: загрузка, подпись, порядок, удаление |
| `vendor/quill/` | Quill 2 (`quill.js`, `quill.snow.css`), лежит локально |
| `vendor/vue/` | Vue 3, глобальная сборка (`vue.global.prod.js`) |

## Как это устроено

- Сборщика (webpack, vite) нет: скрипты подключаются тегом `<script>` в `templates/admin/form.html`.
- `images.js` работает с JSON-эндпоинтами из [routes/admin_api.py](../routes/admin_api.py). Текст ошибок
  берётся из поля `detail` ответа сервера.
- Без JS форма записи остаётся рабочей: вместо Quill виден обычный `textarea`.
- Файлы в `vendor/` — чужие библиотеки, их не правят. Обновлять только целиком, новой версией файла.
- Цвета и размеры задаются переменными в начале `style.css`; в остальных CSS-файлах берутся оттуда.
- Адаптивность через медиа-запросы во всех трёх CSS-файлах; сайт рассчитан на телефоны.
- Загруженные картинки сюда не попадают: они лежат в `uploads/` и отдаются по `/uploads/...`.
