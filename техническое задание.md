Основа сервиса - записи о тренировке собак. У записи есть категория, тег, краткое и полное описание.
Записи показываются на странице в виде карточек, при нажатии открывают страницу.
В админке можно добавлять и удалять теги, сами записи, редактировать их.
Форма добавления записи использует quill для комфортного форматирования, в бд сохраняется таким образом, что тело записи это html шаблон. Теги отдельно, для связи many-to-many.
Присутствует возможность загружать изображения. Отдельно "аватарка карточки" отсутствует, просто первое изображение ставится на превью.
Имеется навигация по категориям.
Предустановленные категории: команда, упражнение, игра, игрушка.
Есть методы для выгрузки всей бд в json файл (текстовой ее части), удобной для машинного парсинга.
Сайт строго адаптивен под мобильные устройства.
