# Тренируем собачку

Справочник по тренировке собак: записи (команды, упражнения, игры, игрушки) с категорией,
тегами и картинками. Публичные страницы для читателей и админка для автора.

Стек: FastAPI + Jinja2 + SQLAlchemy + SQLite + Pydantic. Редактор текста Quill и менеджер
картинок на Vue 3 лежат локально в `static/vendor/`, сборщика нет.

ТЗ: [техническое задание.md](техническое%20задание.md) (кратко) и
[расширенное техническое задание.md](расширенное%20техническое%20задание.md) (подробно).

## Запуск

Windows, PowerShell:

```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
copy .env.example .env      # поправь под себя
python main.py
```

WSL / Linux:

```bash
python -m venv venv && source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env        # поправь под себя
python main.py
```

Сайт: http://127.0.0.1:8000, админка: http://127.0.0.1:8000/admin.

- Запускать нужно **из корня проекта**.
- Окружение `venv` привязано к системе, где создано: папка `venv\Scripts` (Windows) не работает
  в WSL, и наоборот. Создавай отдельное окружение там, откуда запускаешь.
- База (`data/app.db`) и папка `uploads/` создаются при первом запуске.
- Админка **не защищена паролем**: любой, кто открыл адрес, может править записи.

## Тесты

```bash
python -m pytest
```

Тесты работают с базой в памяти и временной папкой для картинок, настоящие данные не трогают.

## Команды в терминале

```bash
python -m cli export [-o файл.json]       # выгрузка записей в JSON
python -m cli import файл.json            # добавить и обновить записи (по id)
python -m cli import файл.json --replace  # заменить всё (только отсюда, не через сайт)
python -m cli backup                      # копия базы в backups/
python -m cli check-files                 # картинки без записи и записи без файла
```

Перед `import` автоматически делается копия базы. Файл с ошибками не принимается целиком,
база при этом не меняется.

Схема БД без миграций: чтобы изменить схему, сделай `export`, удали `data/app.db`,
запусти приложение и сделай `import`.

## Как это работает

Запрос идёт так: **браузер → роут (`routes/`) → функции работы с БД (`data/`) →
шаблон (`templates/`) → HTML**. Данные формы сначала проверяет схема `RecordForm`
(`data/schemas.py`), основной текст очищает `sanitize_html` (`utils/text.py`).

## Настройки (`.env`)

Файл `.env` не попадает в git. Образец: `.env.example`. Все переменные описаны в `core.py`,
кроме `LOG_LEVEL` (читает `utils/logger.py`).

| Переменная | По умолчанию | Что делает |
|-----------|--------------|-----------|
| `LOG_LEVEL` | `INFO` | Уровень логов |
| `HOST`, `PORT` | `127.0.0.1`, `8000` | Адрес и порт при запуске `python main.py` |
| `SITE_NAME` | `Тренируем собачку` | Название сайта в шапке и заголовках |
| `SITE_URL` | `http://127.0.0.1:8000` | Адрес сайта без слэша в конце |
| `SITE_TIMEZONE` | `Europe/Moscow` | Часовой пояс для дат на страницах |
| `DATABASE_PATH` | `data/app.db` | Файл базы (относительный путь считается от корня проекта) |
| `UPLOAD_DIR` | `uploads` | Папка для картинок |
| `VIDEO_ENABLED` | `false` | Поле видео в записи и в экспорте |
| `MAX_UPLOAD_MB` | `10` | Максимальный размер загружаемой картинки |
| `MAX_IMAGES_PER_RECORD` | `10` | Максимум картинок в записи |
| `PAGE_SIZE` | `12` | Записей на странице главной |
